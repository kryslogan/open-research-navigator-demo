OPEN RESEARCH NAVIGATOR — DAUGHTERS OF THE DUST DEMO

Purpose
-------
A film-centered public-humanities proof of concept with Open Research Navigator
embedded throughout the experience.

-----
index.html
app.js
config.js
daughters-content.json
.nojekyll

Temporary access code
---------------------
melanie-demo

What the demo shows
-------------------
- Attractive film-centered landing page
- Temporary self-attested age + purpose profile
- Age-aware hiding/filtering of selected sensitive material
- Purpose-dependent research detail
- Daughters of the Dust film page with public-history context
- Julie Dash / UCLA / L.A. Rebellion / Gullah Geechee / migration /
  preservation pathways
- Instructor-developed Matrilineal Diasporic Spiral clearly labeled as
  project interpretation, not universal cultural formula
- Contextual “Ask the Navigator” buttons throughout the page
- 5 results by default; 10 enabled only for adult educator/research modes
- Rich results with abstracts and direct connection highlighting
- Checkbox selection
- Timestamped research trail
- Per-result typed notes
- Touch / stylus / mouse scratchpad
- Related-material links
- TXT export
- Self-contained HTML session export for adult educator/research profiles
- Text-size / contrast controls
- Responsive design and reduced-motion support
